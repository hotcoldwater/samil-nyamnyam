삼일냠냠 디자인 토큰 (Design Tokens) v3
출처: 레퍼런스 팔레트 #FAF3E1 · #F5E7C6 · #FA8112 · #222222 + 데모 화면 + 기획서 v5 + 목업 피드백
테마: Light 1종 / 모바일 웹앱 기준

[화면 구조]
- 화면: 시작(흰 바탕, 3D 간식 일러스트 모션, 화면을 누르면 간식현황으로 이동) / 간식현황 / 간식 상세 / 간식수령·태그 / 간식수령·간식 고르기 / 리뷰 쓰기(바텀시트) / 내 계정.
- 상단바: 로고만(포인트 표시 없음). surface 바탕 + 아래 line 1px + shadow-header.
- 간식현황의 모든 간식은 각자의 상세로 이어진다. 상세의 남은 수량 카드는 수량·상태·썸네일만(입고량 대비 막대 없음). 리뷰가 없으면 빈 상태 카드.
- '오늘 내 수령 기록'·적립 내역은 최신순. 포인트는 0P에서 시작, 수령 참여 1회 +20P, 리뷰 1건 +30P.
- 하단 탭바(간식현황 · 간식수령 및 제보 · 내 계정)는 간식 상세 포함 모든 화면에. 수령 참여·리뷰 작성은 '간식수령 및 제보' 탭에서만 하고 간식 상세에는 행동 버튼을 두지 않는다.
- 시즌 간식 카드: 좌우로 넘기는 캐러셀(스냅), 아래 점 인디케이터(현재 20×6 brand-500, 나머지 6×6 line-strong).
- 리뷰 쓰기: 바닥 시트(상단 모서리 28px, 뒤 화면 45% 어둡게). 만족도 별 → 또 먹을래요?(하나) → 태그(여러 개) → 한마디(선택·40자) → '리뷰 남기고 30P 받기'.

[사용 원칙]
- 페이지 배경 ground(크림), 카드 surface, 카드 안 보조 타일 surface-sand. 시작 화면만 splash-ground(흰색).
- 로고: '삼일'은 ink-900, '냠냠'은 logo-accent(#F34F00).
- 주요 버튼(화면당 하나): 배경 action-primary(#C05408), 흰 글자 on-action, 그림자 shadow-action.
- 할 일 버튼(리뷰 작성): action-tonal + on-tonal + 앞 연필 아이콘, 높이 36px. 완료 표시(리뷰 완료): status-done-bg(회색) + status-done-fg + 앞 체크 아이콘, 같은 크기, 누를 수 없음.
- 선택 칩: 선택 전 chip-bg + 1px chip-border + chip-fg(600) / 선택 후 chip-selected-bg + chip-selected-fg(700). 칩·별 버튼은 브라우저 기본 모양을 지우고 색을 직접 지정(안 그러면 하늘색 기본 버튼이 보임).
- 별점 입력: 고른 별 star-filled + star-filled-stroke, 안 고른 별 star-empty + star-empty-stroke. 별 40px, 터치 52px, ground 칸 안 가운데. 'n점/별을 눌러 주세요'는 제목 오른쪽 한 줄.
- 사진 카드 스크림: 따뜻한 갈색 그라데이션 rgba(74,38,8) 0% 투명 → 42% 0.6 → 100% 0.8, 위에 흰 글자. 회색 스크림 금지.
- 이미지: 사진이 없으면 이모지 대신 둥글고 광택 있는 3D 간식 일러스트(붕어빵은 얼굴 없이 노릇한 색과 틀 무늬만). 썸네일 바탕 illust-thumb-bg, 큰 카드 바탕 illust-*(붕어빵/요거트/아이스크림) + illust-halo 원. 일러스트는 천천히 떠다니고, 동작 줄이기 설정에서는 정지.
- brand-500(#FA8112)은 진행 바·인디케이터 같은 면에만. 글자색·버튼 바탕으로 쓰지 않는다.
- 오렌지 글자: 흰 카드 위 brand-700, 크림 바탕·brand-100 위 brand-800.
- 상태는 항상 '점 + 글자'로(예: ● 6개 · 부족). 재고: 30% 초과 충분/30% 이하 부족/0 소진. 혼잡도: Q<5 여유, 5≤Q<15 보통, Q≥15 혼잡, 제보 3명 미만 확인 중.
- 말투: 해요체, 짧고 다정하게. 숫자에는 단위(약 12개 남음, 2명).
