# 삼일냠냠

탕비실 간식, 뭐가 남았고 줄은 어떤지 가기 전에 확인하는 AP 사내 간식 관리 웹앱의 디자인 시스템입니다. 기획서 v5와 현재 데모 화면의 구조(간식현황 · 간식수령 및 제보 · 내 계정)를 그대로 두고, 레퍼런스 팔레트(colorhunt `#FAF3E1 · #F5E7C6 · #FA8112 · #222222`)와 레퍼런스 앱들의 따뜻한 음식 사진 중심 무드로 옮겨 정리했습니다.

## 디자인 원칙

**간식이 먼저 말한다.** 시즌 간식은 사진이나 3D 일러스트가 화면을 채우는 큰 카드(`size-hero-card`, `radius-xl`, `shadow-hero`)로 보여주고, 좌우로 넘겨 다음 시즌 간식을 봅니다. 메뉴명·남은 수량·별점·입고 시각은 카드 하단의 따뜻한 갈색 `scrim` 그라데이션(0% 투명 → 42% 60% → 100% 80%) 위에 `on-dark` 글자로 얹습니다. 레퍼런스의 음식 카드처럼 간식이 주인공이고, UI는 크림색 바탕(`ground`)에 물러나 있습니다. 시작 화면만 흰 바탕(`splash-ground`)에 일러스트가 떠다니는 모션을 쓰고, 화면 아무 곳이나 누르면 간식현황으로 넘어갑니다('화면을 누르면 시작해요' 안내가 깜빡임). 모션 무대는 390px 기준 배치를 가로 중앙에 둡니다.

**따뜻한 크림, 오렌지는 아껴서.** 화면 대부분은 `ground`(크림)와 `surface`(카드), `surface-sand`(보조 타일)입니다. 오렌지는 한 화면에 한두 곳 — 주요 버튼(`action-primary`), 로고의 '냠냠'(`logo-accent`), 진행 바·캐러셀 인디케이터(`brand-500`) — 에만 씁니다. 오렌지가 많아지면 상태색(부족·소진)과 구분이 흐려집니다.

**숫자는 정직하게.** 재고는 총무팀 확인값 기준의 '약 n개' 추정치이고, 혼잡도는 표본이 3명 미만이면 '확인 중'입니다. 추정·모의 값은 늘 그렇다고 표시합니다(`caption` + `ink-500`, 데모는 점선 '데모' 표식).

## 색 사용 규칙

| 상황 | 토큰 |
| --- | --- |
| 페이지 배경 | `ground` |
| 카드·탭바·시트 | `surface` + `shadow-card` |
| 카드 안 보조 타일(지금 상태, 또 먹을래요 92%) | `surface-sand` |
| 주요 버튼 | 배경 `action-primary`(= `brand-700`), 라벨 `on-action` 흰색(4.65:1), 그림자 `shadow-action`, 눌림 `action-primary-pressed` |
| 보조 행동 버튼(리뷰 쓰기 +30P) | 배경 `action-tonal`(= `brand-100`), 글자·앞 아이콘 `on-tonal`. 완료 표시(수령 참여 +20P)는 같은 모양에 `stock-ok-soft` + `stock-ok` |
| 상단바 | 배경 `surface`, 아래 `line` 1px + `shadow-header` |
| 로고 '냠냠' | `logo-accent`(#F34F00), '삼일'은 `ink-900` |
| 흰 카드 위 오렌지 글자(활성 탭, '20P') | `brand-700` |
| 크림 바탕·`brand-100` 위 오렌지 글자(포인트 필 '0P') | `brand-800` |
| 큰 수치(포인트 잔액) | `display-num` + `brand-600`(흰 카드 위에서만) |
| 시즌 배지 | 배경 `season`, 글자 `ink-900` |
| 상시 배지 | 배경 `surface-sand`, 글자 `ink-700` |

`brand-500`(#FA8112)은 크림 위 2.3:1, 흰 글자를 올려도 2.6:1이라 **글자색으로도, 버튼 바탕으로도 쓰지 않습니다.** 주요 버튼은 한 단계 짙은 `brand-700` 바탕에 흰 글자를 씁니다 — 밝은 오렌지에 검은 글자를 올리는 방식은 촌스러워 보여 v2에서 바꿨습니다. 로고 '냠냠'만은 삼일회계법인(PwC) 오렌지에 맞춘 `logo-accent`(#F34F00)를 씁니다(로고는 대비 기준 예외).

버튼은 강약 두 단계만 둡니다. 화면의 가장 중요한 행동 하나는 `action-primary`(짙은 주황 + 흰 글자), 곁가지 행동은 `action-tonal`(옅은 주황 + 짙은 주황 글자, 앞에 관련 아이콘). 한 화면에 `action-primary`는 하나만.

### 상태색 — 재고와 혼잡도

기획서의 기준을 그대로 색에 묶습니다. 상태는 항상 **점 + 글자**로 함께 표기하고 색만으로 구분하지 않습니다.

| 의미 | 재고(상시 간식) | 혼잡도(대기 인원 중앙값 Q) | 글자 | 점 | 칩 배경 |
| --- | --- | --- | --- | --- | --- |
| 좋음 | 직전 입고량의 30% 초과 | 여유 (Q < 5) | `stock-ok` | `stock-ok` | `stock-ok-soft` |
| 주의 | 30% 이하 → 부족 | 보통 (5 ≤ Q < 15) | `stock-low` | `stock-low-dot` | `stock-low-soft` |
| 나쁨 | 0 → 소진 | 혼잡 (Q ≥ 15) | `stock-out` | `stock-out` | `stock-out-soft` + `stock-out-strong` |
| 모름 | — | 확인 중 (유효 제보 3명 미만) | `ink-500` | `pending` | `surface-sunken` |

예: `● 6개 · 부족`, `● 혼잡 · 제보 5명 · 20:51 갱신`, `● 확인 중 · 최근 2분 제보가 3명 미만이에요`.

### 선택 칩·완료 표시·별점

| 상황 | 토큰 |
| --- | --- |
| 선택 칩, 선택 전 | 바탕 `chip-bg`, 테두리 1px `chip-border`, 글자 `chip-fg` 600 |
| 선택 칩, 선택 후 | 바탕·테두리 `chip-selected-bg`, 글자 `chip-selected-fg` 700 |
| 할 일 버튼(리뷰 작성) | `action-tonal` + `on-tonal`, 앞에 연필 아이콘, 높이 36px |
| 완료 표시(리뷰 완료) | `status-done-bg` + `status-done-fg`, 앞에 체크 아이콘, 같은 크기. 누를 수 없음 |
| 별점 입력 | 고른 별 `star-filled` + `star-filled-stroke`, 안 고른 별 `star-empty` + `star-empty-stroke`, 별 40px·터치 52px, `ground` 칸 안 가운데 정렬. 'n점' 안내는 제목 오른쪽 한 줄 |

칩과 별은 브라우저 기본 버튼 모양을 지우고(appearance 없음) 색을 직접 지정합니다 — 지우지 않으면 기기에 따라 하늘색 기본 버튼이 비칩니다.

## 타이포그래피

Pretendard 한 가족(400·600·700·800)으로 씁니다. 제목은 700–800에 자간을 살짝 좁히고(-0.01~-0.02em), 본문은 15/22입니다. 수량·시각·포인트 같은 숫자는 `font-variant-numeric: tabular-nums`로 자릿수를 맞춥니다.

- `display-logo` — 스플래시 로고 '삼일냠냠'
- `display-num` — 적립 포인트, 재이용률
- `hero` — 사진 카드·상세의 메뉴명
- `title-lg / title-md / title-sm` — 화면 제목 / 섹션·카드 제목 / 품목명·버튼
- `body / body-strong` — 본문 / 수량·상태 값
- `caption` — 메타(총무팀 예고, 최근 제보 시각)
- `label` — 탭바, 배지

## 화면 구조

상단바는 로고만(포인트 표시 없음), `surface` 바탕에 `line` 1px과 `shadow-header`. 하단 탭바(간식현황 · 간식수령 및 제보 · 내 계정)는 간식 상세를 포함한 모든 화면에 둡니다. 수령 참여와 리뷰 작성은 '간식수령 및 제보' 탭 한 곳에서만 하고, 간식 상세에는 행동 버튼을 두지 않습니다. 간식현황의 모든 간식(시즌 카드, 입고 예정, 오늘 소진, 상시 목록)은 각자의 상세로 이어지고, 상세의 남은 수량 카드는 수량·상태·썸네일만 보여줍니다(입고량 대비 막대 없음). 오늘의 리뷰가 없으면 빈 상태 카드를 둡니다. '오늘 내 수령 기록'과 적립 내역은 최신순입니다. 리뷰 쓰기는 바닥에서 올라오는 시트(상단 `radius` 28px, 뒤 화면 45% 어둡게)입니다.

## 간격과 모양

4px 그리드(`space-1`…`space-12`)입니다. 화면 좌우 여백과 카드 내부 패딩은 `space-5`(20px), 카드 사이는 `space-3`, 섹션 사이는 `space-8`입니다. 모서리는 둥글고 부드럽게 — 카드와 사진 카드 `radius-xl`(24px), 버튼 `radius-lg`, 썸네일·타일 `radius-md`, 포인트 필·토글·점은 `radius-full`. 그림자는 회색이 아닌 갈색 기운의 따뜻한 그림자(`shadow-card`, `shadow-hero`)로, 크림 바탕에서 탁해 보이지 않게 합니다.

## 말투

해요체, 짧고 다정하게. "간식을 받으셨나요?", "오늘 저녁 입고 예정", "리뷰는 매일 새벽 02:00에 새로 시작돼요". 숫자는 단위를 붙여 바로 읽히게("약 12개 남음", "2명"). 느낌표와 과장은 쓰지 않습니다.

## 이미지와 아이콘

메뉴 이미지는 총무팀이 촬영해 등록한 실제 사진입니다(메인·상세·알림에 같은 사진). 사진이 없을 때는 이모지 대신 둥글고 광택 있는 3D 간식 일러스트를 씁니다 — 노릇하게 구워진 붕어빵(눈·입 같은 얼굴 묘사 없이 틀 무늬만), 도넛, 딸기 요거트, 아이스크림, 버터쿠키, 초코우유, 생수, 커피, 사과, 샌드위치. 썸네일은 `size-thumb` 정사각 `radius-md`에 `illust-thumb-bg` 타일, 큰 카드는 메뉴별 `illust-*` 바탕에 `illust-halo` 원을 깔고 일러스트가 천천히 떠다니게 합니다(동작 줄이기 설정에서는 정지). 탭바 아이콘은 실제 출시 때 단색 라인 아이콘(비활성 `ink-500`, 활성 `brand-700`)으로 바꾸기를 권합니다. 이 시스템에는 아직 로고 파일이 없어 로고는 `display-logo` 글자로만 표기합니다.
